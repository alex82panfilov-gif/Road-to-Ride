# Отказы

| Не делаем | Почему |
|---|---|
| Аккаунты и регистрацию в v1 | Данные о деньгах хранятся у пользователя. Нет вопросов по 152-ФЗ |
| Парсинг auto.ru и Avito | Нарушает правила площадок, есть юридический риск |
| Предложения кредитов и рекламу дилеров | Сайт должен действовать в интересах человека, а не подталкивать к долгам |
| Push-уведомления | Это навязчиво. Вместо них есть напоминание в календарь (.ics) |
| Серии «не пропусти месяц» со штрафами | Копить должно быть приятно, а стыдить человека нельзя |
| Готовые объявления «купи вот эту» | Мы не можем проверить конкретную машину |
