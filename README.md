# Road to Ride

Сайт помогает начинающему водителю понять, какую надёжную машину на автомате он может купить за свою сумму, сколько накопить до заметно лучшего варианта и как не нарваться на проблемы при покупке.

Данные о деньгах остаются в браузере. Стартовые цены в `data/snapshots` — ориентир для каркаса, не подсчёт объявлений. У них уверенность «мало данных».

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

Проверки:

```bash
npm test
npm run validate
npm run build
```

## Как устроено

- Страницы моделей и уровней собираются статически.
- Оценка считается в `lib/score.ts`, прогноз — в `lib/forecast.ts`.
- Карточки моделей — `data/models/*.json`, цены месяца — `data/snapshots/YYYY-MM.json`.
- Копилка — ключ `rtr:v1` в localStorage. Старый ключ `fm:v1` переносится сам. Экспорт — файл `road-to-ride-backup-….json`.

Ежемесячное обновление описано в `docs/AGENT_PROMPT.md`. Отказы первой версии — в `docs/DECISIONS.md`.

## Публикация

Проект рассчитан на Vercel. Бесплатный план Hobby подходит, пока сайт семейный и без рекламы. Подключите свой домен и проверьте открытие с мобильного интернета: у части провайдеров бывают сбои с адресами `*.vercel.app`. Если проблемы останутся, статические JSON легко перенести на другой хостинг.
